# **Prompt Engineering**

Man formuliert Anweisungen an eine KI so, dass sie möglichst **genaue, brauchbare und kontrollierbare Antworten** liefert.



#### Die wichtigsten Bausteine eines guten Prompts

1. **Rolle**

   > „Du bist ein erfahrener Systemadministrator.“

2. **Aufgabe**

   > „Erkläre mir VLANs.“

3. **Kontext**

   > „Ich arbeite im IT-Support eines Systemhauses.“

4. **Zielgruppe**

   > „Erkläre es für einen Einsteiger.“

5. **Format**

   > „Nutze eine Tabelle und danach eine Schritt-für-Schritt-Erklärung.“

6. **Bedingungen**

   > „Verwende kurze Sätze und erkläre Fachbegriffe.“

7. **Beispiele**

   > „Zeige ein Beispiel mit einem Praxisnetzwerk, Server, Switch und Firewall.“





#### Grundstruktur:

Rolle:
Du bist ...

Aufgabe:
Erstelle / erkläre / analysiere ...

Kontext:
Folgende Situation liegt vor: ...

Ziel:
Ich möchte ...

Bedingungen:

- ...
- ...
- ...

Ausgabeformat:

- Tabelle
- Schritt-für-Schritt
- Zusammenfassung



****

#### Prompt Engineering umfasst aber noch mehr.

##### Dazu gehören auch:

- **Zero-Shot Prompting** – Aufgabe ohne Beispiel stellen.
- **Few-Shot Prompting** – der KI Beispiele geben.
- **Context Prompting** – relevante Hintergrundinformationen bereitstellen.
- **Structured Prompting** – klare Abschnitte und Regeln verwenden.
- **Prompt Templates** – wiederverwendbare Vorlagen erstellen.
- **Iterative Prompting** – einen Prompt schrittweise verbessern.
- **Agent Prompts** – einer KI Rolle, Werkzeuge und Arbeitsabläufe geben.
- **System Prompts** – grundlegende Regeln für das Verhalten einer KI festlegen.
